# AI Workplace Productivity Assistant

A modern, responsive React web application designed to help busy professionals streamline daily administrative and workflow tasks using AI-driven automation 
---

🚀 **[View live demo]https://claude.ai/public/artifacts/b314e11e-a32e-414f-91c5-4cb32cd84623**

## Key Features

* **Smart Email Generator:** Draft polished, ready-to-send workplace emails tailored by purpose, target audience, and preferred tone (Formal, Friendly, Persuasive, Assertive, or Empathetic).
* **Meeting Notes Summarizer:** Extract structured key points, unassigned action items with deadlines, and key decisions directly from raw meeting transcripts.
* **AI Task Planner:** Organize and prioritize cluttered to-do lists using urgency matrix scoring and generate realistic daily time blocks.
* **AI Research Assistant:** Produce structured executive briefs complete with key insights, considerations, and actionable next steps on any business topic.
* **AI Chatbot:** An embedded conversational interface for fast workplace Q&A, drafting help, and quick problem-solving.

---

## Tech Stack

* **Frontend:** React 18
* **Styling:** CSS3 (Custom Design Tokens, Sora & Inter Typography, Responsive Layouts)
* **Iconography:** Lucide React
* **AI Engine:** Anthropic Claude API (`claude-sonnet-4-6`)
